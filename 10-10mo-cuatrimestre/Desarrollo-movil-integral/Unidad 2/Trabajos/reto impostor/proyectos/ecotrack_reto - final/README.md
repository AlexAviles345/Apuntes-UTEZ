# Ecotrack_reto — Solución en Tres Capas

Solución con dominio, datos y presentación mediante MVVM. Registra consumos por laboratorio utilizando un repositorio en memoria o una nube simulada, seleccionados en `lib/main.dart`.

Las guías numeradas de actividad, punto de partida, resolución, arquitectura final y pruebas están en el [índice de estudio](../../README.md).

```bash
flutter pub get
flutter run
flutter test -r expanded
bash verificar_capas.sh
flutter analyze
```

`lib/main_mezclado.dart` se conserva como referencia. `test/` y `verificar_capas.sh` mantienen los archivos de evaluación entregados.
