¿Por qué pedimos tu ubicación?

Necesitamos tu ubicación aproximada para adjuntar las coordenadas al reporte técnico y calcular la sucursal más cercana. Solo se usa cuando tú lo confirmas y no se comparte con nadie.

Permiso bloqueado

El navegador tiene bloqueada la ubicación para este sitio. Para reactivarla: toca el ícono de candado/ajustes junto a la URL → Permisos → Ubicación → Permitir, y recarga la página. En iPhone: Ajustes → Privacidad → Localización → Safari (o el sitio web). Mientras tanto, puedes elegir tu zona manualmente.
