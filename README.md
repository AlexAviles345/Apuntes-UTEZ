# Apuntes UTEZ

Bienvenido a mi repositorio de **Apuntes de la Universidad Tecnológica de Emiliano Zapata (UTEZ)**. 
Este repositorio tiene como objetivo almacenar, organizar y documentar los apuntes, prácticas, tareas y recursos de las materias cursadas a lo largo de los semestres.

## Estructura del Repositorio

La organización principal del repositorio está basada en semestres, y dentro de cada semestre, se encuentran las materias correspondientes. Cada materia tiene su propia estructura interna para mantener todo ordenado.

```text
Apuntes-UTEZ/
│
├── 09-9no-semestre/
│   ├── Extraccion-de-Conocimiento-en-Bases-de-Datos/
│   │   ├── README.md       # Descripción e información de la materia
│   │   ├── Apuntes/        # Notas de clase y resúmenes
│   │   ├── Guias/          # Guías de estudio
│   │   ├── Practicas/      # Prácticas realizadas en laboratorio/clase
│   │   ├── Tareas/         # Tareas y trabajos de investigación
│   │   └── Recursos/       # Libros, PDFs, enlaces, datasets, etc.
│   │
│   ├── Materia-2/
│   └── Materia-3/
│
├── 08-8vo-semestre/
├── 07-7mo-semestre/
└── README.md
```

## Convenciones y Uso

- Cada carpeta de semestre (ej. `09-9no-semestre`) agrupa las asignaturas impartidas durante ese periodo.
- Cada carpeta de asignatura (ej. `Extraccion-de-Conocimiento-en-Bases-de-Datos`) debe contar con su propio `README.md` donde se detalla el temario, el objetivo de la materia y la forma de evaluación.
- Los apuntes y documentos se redactan preferentemente en formato Markdown (`.md`) para facilitar su lectura y mantenimiento.

## Archivos Grandes (Git LFS)

Este repositorio está configurado con **Git LFS (Large File Storage)** para el manejo eficiente de archivos multimedia y binarios.
Actualmente, las imágenes optimizadas en formato `.webp` están siendo rastreadas por LFS de manera global. Si planeas agregar archivos pesados en el futuro o si clonas este repositorio en otro equipo, recuerda asegurarte de tener Git LFS instalado.
